# KL Edits - Official Agency Website

Official public website and digital design portfolio for KL Edits.
Features:
- Responsive dual-split Hero Section (KL Edits & ictkusal inspired)
- Interactive 3D Showcase frame
- 12 CV Templates catalog with WhatsApp direct order prefill
- Graphic design portfolio with full-view lightboxes
- Real client live web development links
- Verified social media client reviews
- Standalone zero-dependency HTTP server

## Run Locally
```bash
node server.js
```
Open [http://localhost:3000](http://localhost:3000)
